- **what it does:** picks WHICH satellite every chord of `network_dd_fractional.csv` is differenced against. `"lowest"` = the lexically-lowest satellite present at >= 2 stations. `"oldest"` = the longest CONTINUOUS presence at >= 2 stations, ties -> lexically lowest (an absence erases the age, so a returning satellite re-enters at age 1).

- **⚠ the pre-registered PASS FAILED, and it was the wrong bar:** §6.12.5 asked that the `oldest` arm's as-traced grade match the base's REF-FREE grade; measured, it lands **2.1-3.4x above** it (0.068 / 0.058 / 0.081). - **scope:** narrow. Arm `"oldest"` only when the AS-TRACED CSV must stand alone (a viewer, an archived file, a consumer script that does not re-reference). For any GRADE the fix is the ref-free instruments, not the policy — **an `oldest` trace is quieter, never reference-FREE**: the elected satellite still carries its own slip and re-level history into every chord. **The goldens keep `"lowest"` under a documented manifest exception** — CONTINUITY, not doubt: they are the comparison baseline, and changing which satellite their dd-frac trace references would break continuity with the entire existing record of dd-frac grades, while they are already graded ref-free (strictly better than any reference policy).
- **interlock:** Inert unless `trace_dd_fractional`. The age map lives in `NetworkCarryState` and is NOT snapshotted, so a warm resume restarts ages at zero and re-elects by the tie-break; the run-end switch count makes that visible rather than silent. ⚠ A/B HYGIENE (SPEC_amb_iono §6.13.4): network traces are written CWD-relative to `./logs/`, NOT `build/x64-Release/logs/` (which holds a stale Aug-13 file) — a capture from the wrong dir makes BOTH arms copy the same old file and every trace compares IDENTICAL.
