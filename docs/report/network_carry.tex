\section{Between-epoch carry: arrowhead admissibility and the DD cycle basis}
\label{sec:net-carry}

% Shared with the Network-mode document; \providecommand so the two
% subfiles can be combined in either order without a redefinition error.
\providecommand{\Nss}{\bm{N}_{ss}}            % shared (satellite) normal block
\providecommand{\Nrr}{\bm{N}_{rr}}            % per-station local normal block
\providecommand{\Nsr}{\bm{N}_{sr}}            % shared<->local cross block
\providecommand{\redNss}{\tilde{\bm{N}}_{ss}} % Schur-reduced shared normals
\providecommand{\redus}{\tilde{\bm{u}}_s}     % Schur-reduced shared RHS
\providecommand{\xshared}{\bm{x}_s}           % shared satellite-parameter estimate
\providecommand{\xlocal}[1]{\bm{x}_{#1}}      % station r's private nuisance block
% Doc-local, deliberately non-trivial names (see the subfiles macro-collision note).
\providecommand{\Czmat}{\bm{C}_L}             % cycle-coefficient matrix on local columns
\providecommand{\Czrx}[1]{\bm{C}_{L,#1}}      % ... restricted to one station's columns
\providecommand{\Pzmat}{\bm{P}^{z}}           % carried DD prior covariance
% Pzmat already carries a superscript: these avoid a double-superscript clash.
\providecommand{\Pzinv}{(\bm{P}^{z})^{-1}}
\providecommand{\Pzpost}{\bm{P}^{z+}}
\providecommand{\Pzprior}{\bm{P}^{z,\mathrm{prior}}}
\providecommand{\Bfold}{\bm{B}}               % C_L Nrr^{-1} C_L^T
\providecommand{\Gfold}{\bm{G}}               % Nsr Nrr^{-1} C_L^T
\providecommand{\Mfold}{\bm{M}}               % (P^z + B)^{-1}
\providecommand{\zfreev}{\bm{z}_{\mathrm{free}}}
\providecommand{\Sigss}{\bm{\Sigma}_{ss}}     % datum-as-known shared covariance
\providecommand{\arcset}{\mathcal{E}}         % arc set of the observation graph

The Network-mode document establishes the arrowhead normal-equation
topology and its exact Schur reduction
(\dcref{sec:net-schur}{the per-station Schur reduction section of the
Network-mode document}), and the worked estimability example establishes
the minimum-constraint datum
(\dcref{sec:net-example}{the two-receiver estimability example}).  This
document develops the part that sits between them and is the hardest to
get right in practice: \emph{how information reaches an arrowhead system
from outside the current epoch}.

The question is forced by the structure.  A network producer that solves
each epoch independently throws away everything it learned about the
carrier-phase ambiguities, which are the only genuinely constant
quantities in the problem; a producer that carries them naively destroys
either the sparsity that makes the solve affordable or the datum
invariance that makes the product meaningful.  The resolution has three
parts, developed in order below:

\begin{enumerate}[leftmargin=*, itemsep=1pt]
\item An arrowhead system admits exactly \emph{three} kinds of
      information fold, and which one applies is decided by \emph{which
      columns} the new information touches, not by what it means
      physically (\Cref{sec:net-carry-doors}).
\item The quantity that may be carried is therefore constrained to be
      gauge-free, and the natural gauge-free basis of the ambiguity
      block is the \emph{cycle space} of the receiver--satellite
      observation graph --- the double differences indexed by the
      spanning tree's \emph{chords} (\Cref{sec:net-carry-cycles}).
\item Carrying that basis costs one bounded Woodbury correction per
      connected component, with closed forms for the posterior and for
      an exact innovation test (\Cref{sec:net-carry-fold}).
\end{enumerate}

\Cref{sec:net-carry-example} then carries a two-receiver,
two-satellite network --- the smallest network whose observation graph
has a cycle at all --- through every step with exact arithmetic.

\begin{remark}[Theoretical footing]
Time-linking a \emph{selected} set of linear functions $\bm{z} =
\bm{F}^\Tr\bm{x}$ while re-estimating the remainder fresh each epoch is
the generalised Kalman filter of Teunissen, Khodabandeh \& Psychas
(\emph{J.\ Geod.}\ 95:108, 2021) and the generalised least-squares
filter of Hou \& Zhang (\emph{J.\ Geod.}\ 99:3, 2025).  Both leave one
question open: how to construct the transition $\bm{\Phi}^z$ of the
linked functions across a \emph{changing} linked set.  Choosing $\bm{z}$
to be the cycle basis answers it, because every basis change the graph
can force is then a unimodular integer matrix
(\Cref{sec:net-carry-cycles}).  The spanning-tree S-basis itself is due
to \textcite{deJonge1998processing}, who selects it once and never
re-selects it; the construction here is what that becomes when the basis
must be allowed to move.
\end{remark}

\subsection{Three doors into an arrowhead system}
\label{sec:net-carry-doors}

Write the epoch's system as in
\dcref{sec:net-schur}{the Schur reduction section}: a shared satellite
border $\xshared$, one private block $\xlocal{\rx}$ per station, and
zero station--station coupling.  Suppose we wish to add a Gaussian prior
$\bm{z}\sim N(\hat{\bm{z}}, \Pzmat)$ on some linear function
$\bm{z} = \bm{C}\bm{x}$ of the epoch's parameters.  In information form
this is the increment $\bm{C}^\Tr\Pzinv\bm{C}$ to the normal matrix
and $\bm{C}^\Tr\Pzinv\hat{\bm{z}}$ to the right-hand side.  Where
that increment \emph{lands} decides everything.

\paragraph{Door 1: the shared border.}
If $\bm{C}$ touches only shared columns, the increment lands entirely in
$\Nss$.  Such a fold is \emph{reduction-preserving}:

\begin{samepage}
\begin{quote}
\textbf{Lemma.} For any symmetric $\Delta\bm{N}$ and any $\Delta\bm{u}$
on the shared border,
\[
  \widetilde{\left(\Nss + \Delta\bm{N}\right)} = \redNss + \Delta\bm{N},
  \qquad
  \widetilde{\left(\bm{u}_s + \Delta\bm{u}\right)} = \redus + \Delta\bm{u}.
\]
\emph{Proof.} The Schur subtrahend
$\sum_\rx \Nsr^{\,\rx}(\Nrr^{\,\rx})^{-1}\Nsr^{\,\rx\Tr}$ is a function
of $\Nsr$ and $\Nrr$ only; $\Nss$ enters
\dcref{eq:net-schur-N}{the reduced-normals equation} additively.
\hfill$\square$
\end{quote}
\end{samepage}

The practical consequence is that a border prior may be folded
\emph{before or after} the reduction with identical results, so the
between-epoch carry of the satellite clock and biases costs no second
Schur pass even when it is applied late --- between the null-space rank
gate and the solve, say.  This is what \texttt{addSharedInfo}
(\texttt{filter/NetworkNormalEquations}) exploits: when a reduction is
already cached it folds the delta in place and leaves the cache current.
The dense form of the same carry (\texttt{addSharedPriorDense}) takes a
\emph{covariance} rather than an information matrix for a reason worth
stating: a carried key absent from the current epoch's layout must be
\emph{marginalised}, which is a row/column deletion on $\Pzmat$, whereas
deleting the same rows of $\Pzinv$ would \emph{condition} on the
departed key and bias every survivor.

\paragraph{Door 2: one station's own columns, before the reduction.}
If $\bm{C}$ touches only station $\rx$'s local columns, the increment
lands in $\Nrr^{\,\rx}$.  For a diagonal prior on columns
$c \in \mathcal{C}$ with information weights $\Lambda_c \ge 0$ and
information right-hand sides $\eta_c$,
\begin{equation}
\Nrr^{\,\rx} \mathrel{+}= \sum_{c\in\mathcal{C}} \Lambda_c\,
   \bm{e}_c\bm{e}_c^\Tr,
\qquad
\bm{u}_r^{\,\rx} \mathrel{+}= \sum_{c\in\mathcal{C}} \eta_c\,\bm{e}_c ,
\label{eq:carry-localprior}
\end{equation}
which the implementation applies as a sequence of rank-one updates of
the \emph{cached} $\mathrm{LDL}^\Tr$ factor
(\texttt{addStationPrior}), so the raw $\Nrr$ never has to be stored or
re-factorised and positivity of $\Lambda_c$ keeps the factor
positive-definite by construction.  Unlike door~1 this fold is
\emph{not} reduction-preserving: it changes $\Nrr$, hence the Schur
subtrahend, hence $\redNss$.  It must therefore be applied
\emph{before} the reduction, and there is no post-reduce fast path.
Two properties make it cheap: it is orthogonal to every other station
(the arrowhead has no station--station block to disturb), and it
conditions only $\xlocal{\rx}$.

The two doors have opposite ordering constraints --- door~1 may be late,
door~2 must be early --- and that asymmetry is not a convention but a
direct reading of \dcref{eq:net-schur-N}{the reduced-normals equation}.

\paragraph{Door 3: local columns across several stations.}
If $\bm{C}$ touches local columns of two or more stations, the
information increment $\bm{C}^\Tr\Pzinv\bm{C}$ has a nonzero
$(\rx,\rx')$ block.  It is representable neither as a border increment
nor as a per-station one, and folding it into the unreduced system
\emph{destroys the arrowhead}: the station--station zeros that make the
marginalisation exact and cheap are exactly what it would fill in.

This is not an exotic case.  It is the case that matters, because the
only ambiguity combinations worth carrying are between-station ones ---
a single station's ambiguity is not estimable on its own
(\dcref{sec:net-example-phase}{the phase part of the two-receiver
example}).  The resolution is to fold such a prior \emph{after} the
reduction, by Woodbury through the block-diagonal local normals, using
the per-station factors the reduction has already computed and left
intact.  \Cref{sec:net-carry-fold} gives the algebra; the rest of this
subsection records the two hazards it creates.

\begin{remark}[Post-reduce folds do not compose]
Two door-3 folds applied to the same reduced system are each derived
against the \emph{pristine} $\Nrr$.  Composing them over coupled local
columns is therefore inexact --- it silently drops the cross term
$\Czmat\Nrr^{-1}\bm{C}_{L,\text{other}}^{\Tr}$ of the joint middle
inverse, because neither fold sees the other's augmentation of $\Nrr$.
The implementation makes this structural rather than advisory: the
sum-to-zero ensemble phase gauge (\texttt{foldReducedSumZeroGauges}) and
the carried DD priors (\texttt{foldReducedDdPriors}) are mutually
exclusive, and \texttt{NetworkEstimator::solve} throws if both are set.
Under the invariant carry the phase datum is realised instead by
door~2 --- pre-reduce tree pins --- which compose with a post-reduce
door~3 fold \emph{exactly}, since the fold then reads an
already-pinned factor.
\end{remark}

\begin{remark}[A door-3 fold cannot repair a rank deficiency]
Let $\delta\xshared$ span a null direction of $\redNss$, with the
matching local response $\delta\xlocal{\rx} =
-(\Nrr^{\,\rx})^{-1}\Nsr^{\,\rx\Tr}\delta\xshared$.  If the carried
function is estimable, $\bm{z} = \Czmat\bm{x}_L$ is invariant along that
direction, so $\Czmat\,\delta\bm{x}_L = -\Gfold^\Tr\delta\xshared = 0$
with $\Gfold$ as defined in \Cref{eq:carry-fold-blocks}.  Every column
of $\Gfold$ is therefore orthogonal to the null space, the rank-$K$
update $\Gfold\Mfold\Gfold^\Tr$ adds nothing along it, and the declared
S-basis dimension the rank gate tests is unchanged by the carry.  A
carry that \emph{did} change it would be carrying a gauge, not
information.
\end{remark}

\subsection{The observation graph and its cycle space}
\label{sec:net-carry-cycles}

Door~3 admits only gauge-free functions, so the carried basis must be
chosen accordingly.  The choice is essentially forced, and it is
combinatorial rather than numerical.

\paragraph{The graph.}
Fix a constellation $g$ and a signal $\sigl$.  Let $G_{g,\sigl} = (V,
\arcset)$ be the graph whose vertices $V = \rxset \cup \satset{g}$ are
the receivers and the satellites, and whose \emph{arcs} are the
receiver--satellite pairs carrying an ambiguity this epoch:
$(\rx,\sat) \in \arcset$ iff station $\rx$ tracks satellite $\sat$ on
signal $\sigl$.  There is at most one arc per pair, so an unordered
vertex pair is a unique arc identity (\texttt{ArcKey},
\texttt{filter/NetworkZStore}).  The graph is \emph{bipartite} by
construction: no arc joins two receivers or two satellites.

\paragraph{Trees and chords.}
A connected component with $n_c$ receivers, $m_c$ satellites and
$|\arcset_c|$ arcs has a spanning tree of $n_c + m_c - 1$ edges.  The
remaining
\begin{equation}
K_c \;=\; |\arcset_c| \;-\; (n_c + m_c - 1)
\label{eq:carry-chordcount}
\end{equation}
arcs are the \emph{chords}.  Adding a chord to the tree closes exactly
one cycle --- its \emph{fundamental cycle}, the chord plus the unique
tree path joining its endpoints --- and those $K_c$ cycles are a basis
of the component's cycle space.  \Cref{eq:carry-chordcount} is the
first Betti number of the component; it is the exact number of
independent double differences the component supports, and it is a
property of the \emph{graph}, not of the estimator.

\paragraph{The carried functions.}
Because the graph is bipartite, every cycle alternates
receiver--satellite--receiver--satellite, so it has even length and its
arcs can be signed alternately.  Define, for chord $c$ with fundamental
cycle $\mathcal{C}_c$,
\begin{equation}
z_c \;=\; \sum_{(\rx,\sat)\,\in\,\mathcal{C}_c}
          \sigma_{(\rx,\sat)}\, N^{\sat}_{\rx,\sigl},
\qquad \sigma_{(\rx,\sat)} = \pm 1 \ \text{alternating},
\label{eq:carry-cycle-sum}
\end{equation}
which for the shortest cycle (length four) is a plain double difference
$N^{\sat_1}_{\rx_1} - N^{\sat_1}_{\rx_2} + N^{\sat_2}_{\rx_2} -
N^{\sat_2}_{\rx_1}$, and for a longer fundamental cycle is a
higher-order alternating difference on six or more columns.

\begin{samepage}
\begin{quote}
\textbf{Proposition (gauge-freeness).} $z_c$ is invariant under both
ambiguity gauges of the network model --- the receiver shift
$N^{\sat}_{\rx}\mapsto N^{\sat}_{\rx} - d_{\rx}$ for all $\sat$, and the
satellite shift $N^{\sat}_{\rx}\mapsto N^{\sat}_{\rx} - c^{\sat}$ for
all $\rx$.

\emph{Proof.} A cycle visits each of its vertices exactly once, and each
visited vertex is incident to exactly \emph{two} arcs of the cycle,
which by the alternating signing carry opposite signs.  A shift attached
to that vertex --- $d_\rx$ at a receiver, $c^{\sat}$ at a satellite ---
therefore contributes $(+1)\delta + (-1)\delta = 0$ to
\Cref{eq:carry-cycle-sum}.  Summing over vertices gives invariance.
\hfill$\square$
\end{quote}
\end{samepage}

So $z_c$ touches no shared column at all: the receiver phase bias and
the satellite phase bias cancel \emph{analytically}, not numerically.
Three consequences follow immediately, and together they are the reason
the cycle basis is the right carried object:

\begin{itemize}[leftmargin=*, itemsep=1pt]
\item \textbf{Estimable in every S-system.}  $z_c$ is invariant under
      the datum, so it may be compared across epochs whose datum
      differs, and graded without an S-transform
      (\dcref{sec:net-sbasis}{the minimum-constraint datum section}).
\item \textbf{Integer, and constant between slips.}  $z_c$ is an
      integer combination of integer ambiguities, and its process noise
      is $q_z = 0$ absent a cycle slip.  It is the \emph{only} part of
      the ambiguity block for which a zero-$q$ time link is physically
      correct.
\item \textbf{Basis changes are unimodular.}  Two spanning trees of the
      same arc set give cycle bases related by an integer matrix
      $\bm{T}$ with $\det\bm{T} = \pm1$, so $\bm{z}' = \bm{T}\bm{z}$,
      $\Pzmat{}' = \bm{T}\Pzmat\bm{T}^\Tr$ is an \emph{exact} change of
      basis with no information loss.  Basis churn --- the failure mode
      that defeats every attempt to carry the raw ambiguities, whose
      individual values are datum-dependent --- becomes a non-event by
      construction rather than by hygiene.
\end{itemize}

\paragraph{Graph events are exact operations.}
Every way the graph can change between epochs maps to an exact
operation on the carried $(\hat{\bm{z}}, \Pzmat)$
(\texttt{ZComponent}, \texttt{filter/NetworkZStore}):

\begin{center}\small
\begin{tabular}{@{}p{0.36\linewidth}p{0.58\linewidth}@{}}
\toprule
Graph event & Operation on the store \\
\midrule
Chord dies (arc lost) &
  Drop that row and column of $\Pzmat$ --- pure marginalisation \\
Chord born (arc closes a new cycle) &
  Append an entry initialised by tap-off
  $\hat z_{\text{new}} = \bm{f}^\Tr\hat{\bm{x}}$ with its conditional
  variance and cross-covariances \\
Leaf growth (arc brings in a new vertex) &
  Extends the tree, closes no cycle, touches no $z$ \\
Tree edge dies &
  Pivot a covering chord into the tree
  ($\bm{z}'=\bm{T}\bm{z}$, $\bm{T}$ unimodular), then kill the arc as a
  chord.  An uncovered tree edge is a cut edge: its death splits the
  component, which merely re-partitions existing blocks \\
Components merge &
  Union the two blocks block-diagonally (they were independent),
  promote one bridge arc to the tree, tap off any surplus bridges \\
\bottomrule
\end{tabular}
\end{center}

In the producer these are not applied as a sequence of events.  The
per-epoch driver (\texttt{filter/NetworkInvariantCarryDriver}) is handed
the current epoch's tree/chord partition from the election and computes
the \emph{composed} transform directly: a new chord's fundamental cycle
lies in the previous epoch's cycle space if and only if every arc of
that cycle was present last epoch, and its carried mean is then
$\hat z^{\text{new}}_c = \sum_j w_j\,\hat z^{\text{old}}_j$ with
$w_j$ the incidence of old chord $j$'s arc in the new cycle.  Assembling
$\bm{W}$ over the contributing components gives
$\hat{\bm{z}}^{\text{prior}} = \bm{W}\hat{\bm{z}}^{\text{old}}$ and
$\Pzprior = \bm{W}\Pzmat\bm{W}^\Tr$; a dead chord's column
of $\bm{W}$ is zero (marginalisation), a chord whose cycle uses a
newborn arc is fresh (diffuse prior, so its posterior is the data-only
tap-off), and merges and splits fall out of the contributor gather with
no special case.

\begin{remark}[Why the tree must avoid slipped arcs]
A slip on a \emph{chord} costs exactly one carried DD.  A slip on a
\emph{tree edge} corrupts every fundamental cycle routed through it.
The election therefore prefers slip-free arcs for the tree
(\texttt{network.phase\_datum\_eq34\_slip\_aware\_election}); this is a
structural argument, independent of any detector threshold.
\end{remark}

\subsection{Folding the carried double differences}
\label{sec:net-carry-fold}

Let one connected component carry $K$ double differences with prior mean
$\hat{\bm{z}}$ and covariance $\Pzmat$, expressed as
$\bm{z} = \Czmat\bm{x}_L$ where $\Czmat$ is the $K \times n_L$ signed
incidence matrix of \Cref{eq:carry-cycle-sum} over the epoch's local
ambiguity columns, and $\Czrx{\rx}$ is its restriction to station
$\rx$.  This is a door-3 fold.  Woodbury through the block-diagonal
local normals gives, per component,
\begin{equation}
\Bfold = \sum_\rx \Czrx{\rx}\Nrr^{-1}\Czrx{\rx}^\Tr,
\quad
\Gfold = \sum_\rx \Nsr\Nrr^{-1}\Czrx{\rx}^\Tr,
\quad
\zfreev = \sum_\rx \Czrx{\rx}\Nrr^{-1}\bm{u}_r,
\quad
\Mfold = (\Pzmat + \Bfold)^{-1},
\label{eq:carry-fold-blocks}
\end{equation}
and the reduced system takes the rank-$K$ correction
\begin{empheq}[box=\fbox]{align}
\redNss &\mathrel{+}= \Gfold\,\Mfold\,\Gfold^\Tr,
\label{eq:carry-fold-N}\\
\redus  &\mathrel{+}= \Gfold\,\Mfold\,(\zfreev - \hat{\bm{z}}).
\label{eq:carry-fold-u}
\end{empheq}
Every ingredient of \Cref{eq:carry-fold-blocks} comes from the
\emph{cached} per-station $\mathrm{LDL}^\Tr$ factors, so no
re-reduction is needed and the factors are left pristine; the only new
inverse is the $K \times K$ middle matrix $\Mfold$, which is per
component and bounded.  Back-substitution then returns the
\emph{constrained} locals,
\begin{equation}
\xlocal{\rx} \mathrel{-}=
  \Nrr^{-1}\Czrx{\rx}^\Tr\,\Mfold\,
  \big(\zfreev - \Gfold^\Tr\xshared - \hat{\bm{z}}\big),
\label{eq:carry-fold-backsub}
\end{equation}
so the ambiguities that the quality-control layer and the next epoch's
tap-off read live in the same frame as the fold.

\paragraph{Posterior.}
The value the store carries forward is the shrinkage of the prior
towards the data-implied DD,
\begin{equation}
\hat{\bm{z}}^{+} = \hat{\bm{z}} + \Pzmat\,\Mfold\,\bm{v},
\qquad
\bm{v} = \zfreev - \Gfold^\Tr\xshared - \hat{\bm{z}},
\label{eq:carry-post-mean}
\end{equation}
with covariance, in the datum-as-known shared frame $\Sigss$ (the
solve's shared covariance with every datum-pinned and gauge column
treated as exact),
\begin{equation}
\Pzpost = \underbrace{\left(\Pzmat - \Pzmat\Mfold\Pzmat\right)}
             _{\text{conditional on }\xshared}
             \;+\; \left(\Pzmat\Mfold\Gfold^\Tr\right)\Sigss
                   \left(\Gfold\Mfold\Pzmat\right).
\label{eq:carry-post-cov}
\end{equation}
The first term is the posterior given the border; the second restores
the coupling through it.  Although $\Sigss$ is datum-constrained,
$\Pzpost$ is datum-invariant, because $\bm{z}$ is estimable.

\paragraph{Innovation.}
The same factors give an exact test of the carry against the epoch's
data.  Under the null hypothesis that the carried DD is still valid,
\begin{equation}
\bm{v} = \zfreev - \Gfold^\Tr\xshared - \hat{\bm{z}},
\qquad
\mathrm{Cov}(\bm{v}) = \Mfold^{-1} - \Gfold^\Tr\,\Sigss\,\Gfold ,
\label{eq:carry-innov}
\end{equation}
and $|v_i|/\sqrt{\mathrm{Cov}(\bm{v})_{ii}}$ is the standardised
statistic that flags a slipped carried DD for re-tapping.  The
\emph{minus} sign in \Cref{eq:carry-innov} is not a typo and not a
conservative approximation: $\xshared$ is itself prior-influenced
through \Cref{eq:carry-fold-u}, and subtracting
$\Gfold^\Tr\Sigss\Gfold$ is precisely the correction for having tested
the carry against a solution the carry helped produce.  Consistency
with \Cref{eq:carry-post-mean,eq:carry-post-cov} is direct:
$\Pzmat\Mfold\,\mathrm{Cov}(\bm{v})\,\Mfold\Pzmat = \Pzmat -
\Pzpost$.

\paragraph{The hard-constraint limit.}
Setting $K=1$, $\hat z = 0$ and $\Pzmat \to \bm{0}$ turns
\Cref{eq:carry-fold-N,eq:carry-fold-u} into the rank-one fold of an
exact linear constraint $\sum_\rx z_\rx = 0$ on local columns, with
$\Mfold \to \Bfold^{-1}$.  That is exactly the anchor-free
sum-to-zero phase-bias gauge
(\texttt{foldReducedSumZeroGauges}); the DD prior is its soft
generalisation, which is the cleanest statement of why the two are the
same object and cannot be composed.

\paragraph{Positive-definiteness, and why it must be counted.}
$\Pzmat + \Bfold$ is positive-definite in exact arithmetic.  It can
fail to be so numerically --- a stiff carry ($\Pzmat$ near zero) added
to an ill-conditioned $\Bfold$ subtracts operands of similar magnitude
to reach a much smaller answer.  When it fails, the only safe action is
to fold \emph{inertly}, $\Mfold := \bm{0}$, which leaves the reduced
system untouched and makes the posterior equal the prior.

That branch is silent by construction, and silence here is dangerous in
a specific way: the component's carried sub-state stops taking data
while every downstream reading of it --- its formal $\sigma$, the
innovation test, any ambiguity-resolution probe --- continues to report
on a quantity that is no longer being updated.  A carry can therefore
diffuse for hundreds of epochs behind clean-looking logs.  The
implementation consequently treats the PD screen as \emph{always-on
telemetry} rather than as an internal detail: per-fold counts of
degenerate blocks and their dimension, the worst relative pivot, and
the count of any repairs are exposed unconditionally
(\texttt{DdFoldStats}, \texttt{filter/NetworkNormalEquations}), and an
optional equilibrated factorisation with a scale-relative pivot test
replaces the absolute one.  The general rule this instantiates: an
inert path needs a counter, because the absence of an error is not
evidence that the mechanism ran.

\subsection{Worked example: the smallest network with a cycle}
\label{sec:net-carry-example}

We now carry a complete network through every step above with exact
arithmetic.  The network is the smallest one whose observation graph has
a cycle at all: two receivers, two satellites, one signal.  As in
\dcref{sec:net-example}{the two-receiver estimability example},
everything inessential is stripped --- coordinates known so the
geometric range is removed, one frequency, no atmosphere, noise-free
data, unit weights --- so that every number below is exact.  Ambiguities
are in cycles.

\paragraph{Model and truth.}
With geometry and the receiver/satellite clocks removed by the code
observations, the carrier phase reduces to
\begin{equation}
\phaseo^{\sat}_{\rx} \;=\; \beta_\rx \;+\; b^{\sat} \;+\; N^{\sat}_{\rx},
\qquad \rx \in \{A,B\},\quad \sat \in \{1,2\},
\label{eq:carry-ex-model}
\end{equation}
where $\beta_\rx$ is the receiver phase bias, $b^{\sat}$ the satellite
phase bias (the producer's target), and $N^{\sat}_{\rx}\in\mathbb{Z}$
the ambiguity.  Take as truth
\[
\beta_A = 0.30,\quad \beta_B = -0.20,\qquad
b^1 = 0.10,\quad b^2 = -0.15,
\]
\[
N^1_A = 3,\quad N^2_A = -1,\quad N^1_B = 5,\quad N^2_B = 2,
\]
which through \Cref{eq:carry-ex-model} gives the four observations
\begin{center}
\begin{tabular}{@{}lcc@{}}
\toprule
$\phaseo^{\sat}_{\rx}$ & $\sat = 1$ & $\sat = 2$ \\
\midrule
$\rx = A$ & $3.40$ & $-0.85$ \\
$\rx = B$ & $4.90$ & $\phantom{-}1.65$ \\
\bottomrule
\end{tabular}
\end{center}

\paragraph{The graph, its tree, and its one chord.}
The observation graph has $n_c = 2$ receivers, $m_c = 2$ satellites and
$|\arcset_c| = 4$ arcs, so by \Cref{eq:carry-chordcount} its spanning
tree has $2 + 2 - 1 = 3$ edges and it has exactly $K_c = 1$ chord
(\Cref{fig:carry-ex-graph}).  Take the tree to be
$\{(A,1),(A,2),(B,2)\}$; the chord is then $(B,1)$, and its fundamental
cycle $B \to 1 \to A \to 2 \to B$ gives the single carried function
\begin{equation}
z \;=\; N^1_B - N^1_A + N^2_A - N^2_B .
\label{eq:carry-ex-z}
\end{equation}

Two checks of the Proposition, both exact.  From the truth,
$z = 5 - 3 + (-1) - 2 = -1$: an integer, as it must be.  From the
\emph{observations} alone, without estimating anything,
\[
(\phaseo^1_B - \phaseo^2_B) - (\phaseo^1_A - \phaseo^2_A)
  = 3.25 - 4.25 = -1,
\]
because $\beta_A$, $\beta_B$, $b^1$ and $b^2$ all cancel in the double
difference.  The single number $-1$ is what the carry transports; every
other parameter in this section will turn out to depend on the datum.

\paragraph{The tree pins are the datum; the chord is left free.}
Model \Cref{eq:carry-ex-model} has $2+2+4 = 8$ unknowns and $4$
observations, hence a four-dimensional null space (choose
$\delta\beta_A,\delta\beta_B,\delta b^1,\delta b^2$ freely; the
$\delta N^{\sat}_{\rx}$ follow).  Pinning the three \emph{tree}
ambiguities $N^1_A = N^2_A = N^2_B = 0$ removes three of those four
dimensions, leaving the single direction
$(\beta_A,\beta_B,b^1,b^2)\mapsto(\beta_A+t,\ \beta_B+t,\ b^1-t,\ b^2-t)$
--- the one remaining receiver-versus-satellite gauge, which is the
network's clock gauge in miniature.  It is removed by one \emph{shared}
pin, $b^1 \equiv 0$.

This is the whole datum architecture in four arcs: the tree edges are
pinned through door~2 (locally, pre-reduce), the last gauge through the
shared minimum-constraint datum, and the chord is left free --- it is
the only ambiguity that carries information rather than convention.  For
tidy arithmetic the pins are taken here as \emph{exact}; the
implementation realises them as tight finite priors folded by
\texttt{addStationPrior}, which is why the pinned columns remain
present in $\Nrr$ there.  One consequence of the exact-pin idealisation
should be named: with the tree ambiguities identically zero, $\Czmat$
in \Cref{eq:carry-ex-z} collapses onto the chord's own column.  With
finite pins it retains all four entries, and the fold algebra below is
unchanged in form.

\paragraph{Arrowhead blocks.}
Order the shared block $\xshared = [\,b^1, b^2\,]^\Tr$ and the free
locals $\xlocal{A} = [\,\beta_A\,]$, $\xlocal{B} =
[\,\beta_B,\ N^1_B\,]^\Tr$.  With unit weights the blocks of
\dcref{eq:net-blocks}{the per-station block definitions} are
\[
\Nss^{\,A} = \bm{I}_2,\quad
\Nsr^{\,A} = \begin{bmatrix}1\\1\end{bmatrix},\quad
\Nrr^{\,A} = \begin{bmatrix}2\end{bmatrix},\quad
\bm{u}_s^{\,A} = \begin{bmatrix}3.40\\-0.85\end{bmatrix},\quad
\bm{u}_r^{\,A} = \begin{bmatrix}2.55\end{bmatrix},
\]
\[
\Nss^{\,B} = \bm{I}_2,\quad
\Nsr^{\,B} = \begin{bmatrix}1&1\\1&0\end{bmatrix},\quad
\Nrr^{\,B} = \begin{bmatrix}2&1\\1&1\end{bmatrix},\quad
\bm{u}_s^{\,B} = \begin{bmatrix}4.90\\1.65\end{bmatrix},\quad
\bm{u}_r^{\,B} = \begin{bmatrix}6.55\\4.90\end{bmatrix},
\]
with $(\Nrr^{\,B})^{-1} = \left[\begin{smallmatrix}1&-1\\-1&2
\end{smallmatrix}\right]$.  There is no $A$--$B$ block: the stations
share only $b^1$ and $b^2$.

\paragraph{Schur reduction.}
Eliminating each station's locals through
\dcref{eq:net-schur-N}{the reduced-normals equation} gives
\[
\Nss^{\,A} - \Nsr^{\,A}(\Nrr^{\,A})^{-1}\Nsr^{\,A\Tr}
  = \begin{bmatrix}\phantom{-}0.5 & -0.5\\ -0.5 & \phantom{-}0.5\end{bmatrix},
\qquad
\bm{u}_s^{\,A} - \Nsr^{\,A}(\Nrr^{\,A})^{-1}\bm{u}_r^{\,A}
  = \begin{bmatrix}\phantom{-}2.125\\ -2.125\end{bmatrix},
\]
while station $B$ contributes \emph{exactly zero} to both: it has two
observations and two free locals, so eliminating them absorbs its rows
entirely.  Summing,
\begin{equation}
\redNss = \begin{bmatrix}\phantom{-}0.5 & -0.5\\ -0.5 & \phantom{-}0.5\end{bmatrix},
\qquad
\redus = \begin{bmatrix}\phantom{-}2.125\\ -2.125\end{bmatrix},
\qquad
\mathrm{eig}(\redNss) = \{0,\,1\}.
\label{eq:carry-ex-reduced}
\end{equation}
The reduced system has rank $1$ and one zero eigenvalue, whose
eigenvector is $[1,1]^\Tr$ --- exactly the one gauge predicted above.
A null-space rank gate declaring dimension $1$ for this configuration
would pass; declaring $0$ or $2$ would throw
(\dcref{sec:net-sbasis}{the minimum-constraint datum section}).

\paragraph{Datum, solve, back-substitute.}
Applying the shared pin $b^1 \equiv 0$ to
\Cref{eq:carry-ex-reduced} and solving gives $\hat b^2 = -4.25$, and
back-substituting through
\dcref{eq:net-backsub}{the back-substitution equation},
\[
\hat\beta_A = 3.40,
\qquad
\hat\beta_B = 5.90,
\qquad
\hat N^1_B = -1.00 .
\]
The fit is exact (all four residuals vanish), and the result agrees to
machine precision with a dense stacked solve of the same system, which
is the lossless-marginalisation claim of
\dcref{sec:net-schur}{the Schur reduction section} made arithmetic.

Note how little of this resembles the truth: the estimated satellite
phase bias $\hat b^2 = -4.25$ has nothing to do with $b^2 = -0.15$, and
$\hat N^1_B = -1$ has nothing to do with $N^1_B = 5$.  Each has absorbed
the datum.  But the chord's double difference in this frame is
\[
\hat z = \hat N^1_B - \hat N^1_A + \hat N^2_A - \hat N^2_B
       = -1 - 0 + 0 - 0 = -1,
\]
identical to the truth and to the value read directly off the
observations.  Datum-invariance is not an asymptotic property here; it
is an identity.

\paragraph{Folding a carried DD.}
Now suppose the previous epoch handed us this chord.  With
$\Czmat = [\,0\ \ 1\,]$ on station $B$ (one row, the exact-pin
collapse noted above), \Cref{eq:carry-fold-blocks} gives
\[
\Bfold = 2,
\qquad
\Gfold = \begin{bmatrix}\phantom{-}1\\-1\end{bmatrix},
\qquad
\zfreev = 3.25 ,
\]
and the identity $z = \zfreev - \Gfold^\Tr\xshared = 3.25 - 4.25 = -1$
recovers the DD, confirming that $\zfreev$ is a data-only quantity in
the correction frame rather than the DD itself.  Observe also that
$\Gfold^\Tr[1,1]^\Tr = 0$: the fold direction is orthogonal to the
gauge, exactly as the second Remark of \Cref{sec:net-carry-doors}
requires, so no choice of prior can make this carry fix the datum.

\emph{A consistent carry is a no-op.}  With $\hat z = -1$ and a rigid
prior $\Pzmat = 0$, \Cref{eq:carry-fold-N,eq:carry-fold-u} reproduce
$\hat b^2 = -4.25$, $\hat\beta_A = 3.40$, $\hat\beta_B = 5.90$,
$\hat N^1_B = -1$ and zero residuals.  The innovation is
$v = 3.25 - 4.25 - (-1) = 0$.  Carrying information the data already
implies changes nothing --- as it should.

\emph{A stale carry warps everything.}  Now suppose the chord slipped by
one cycle and the carry did not notice, so $\hat z = 0$ is folded
rigidly.  Re-solving gives
\begin{center}
\begin{tabular}{@{}lccc@{}}
\toprule
 & $\hat b^2$ & $\hat\beta_A$ & $\hat\beta_B$ \\
\midrule
consistent carry ($\hat z = -1$) & $-4.25$ & $3.40$ & $5.90$ \\
stale carry ($\hat z = 0$)       & $-3.75$ & $3.15$ & $5.15$ \\
\bottomrule
\end{tabular}
\end{center}
and post-fit residuals of $+0.25$, $-0.25$, $-0.25$, $+0.25$ cycles on
rows $(A,1)$, $(A,2)$, $(B,1)$, $(B,2)$ respectively.  A one-cycle error
in a stiff carried quantity did not stay in the ambiguity that slipped:
it moved the \emph{emitted satellite phase bias} by half a cycle and
smeared the remainder evenly over every observation in the network.
This is the general mechanism by which a stale zero-$q$ carry damages a
solution --- the network has no way to reject information asserted with
infinite confidence, so it redistributes the contradiction into whatever
states can absorb it.  It is also why any zero-$q$ time link requires a
wired slip response before it may be armed.

\emph{The innovation test, and its limits.}  From
\Cref{eq:carry-innov}, with $\Sigss = \mathrm{diag}(0,\,1)$ (the pinned
column treated as exact),
\[
v = 3.25 - 3.75 - 0 = -0.5,
\qquad
\mathrm{Cov}(v) = \Mfold^{-1} - \Gfold^\Tr\Sigss\Gfold = 2 - 1 = 1,
\qquad
\frac{|v|}{\sqrt{\mathrm{Cov}(v)}} = 0.5 .
\]
The test sees the slip, but at only $0.5\sigma$ --- far below any
sensible flag threshold.  The reason is visible in the residual table:
with four observations and no redundancy to speak of, half the error was
absorbed by the parameters, so only half of it reached the innovation.
The statistic is exact, not conservative; its \emph{power} is a property
of the network's redundancy, and a two-by-two network has almost none.
This is the honest reading of any estimation-side slip test: it is
diagnostic of the carry only in proportion to how much the network
could not absorb.

\paragraph{A tree-edge death: the unimodular pivot.}
The two-by-two network is too small to show a pivot, because with one
chord every tree edge whose death matters is a cut edge.  Add a third
satellite: $n_c = 2$, $m_c = 3$, $|\arcset_c| = 6$, so the tree has four
edges and there are $K_c = 2$ chords.  Take the tree
$\{(A,1),(A,2),(A,3),(B,1)\}$ with chords $(B,2)$ and $(B,3)$, giving
\[
z_1 = N^2_B - N^2_A + N^1_A - N^1_B,
\qquad
z_2 = N^3_B - N^3_A + N^1_A - N^1_B .
\]
Now let the tree edge $(A,1)$ die.  It is covered by both chords, so a
covering chord --- say $(B,2)$ --- is promoted into the tree, and the
dead arc is killed as a chord.  Against the new tree
$\{(A,2),(A,3),(B,1),(B,2)\}$ the cycle basis is
\[
z_1' = N^1_A - N^1_B + N^2_B - N^2_A = z_1,
\qquad
z_2' = N^3_B - N^3_A + N^2_A - N^2_B = z_2 - z_1,
\]
that is $\bm{z}' = \bm{T}\bm{z}$ with
\[
\bm{T} = \begin{bmatrix}\phantom{-}1 & 0\\ -1 & 1\end{bmatrix},
\qquad \det\bm{T} = 1 .
\]
$\bm{T}$ is integer with unit determinant, so
$\Pzmat{}' = \bm{T}\Pzmat\bm{T}^\Tr$ is an exact change of basis; the
carried covariance is transformed, not approximated.  Killing the dead
arc's row of $\bm{z}'$ is then a marginalisation, and the surviving
$z_2'$ continues with no loss.  Had the carried quantity been the raw
ambiguities instead of the cycle basis, this same graph event would have
demanded an S-transformation of a datum-dependent state --- the failure
mode the cycle basis exists to eliminate.
