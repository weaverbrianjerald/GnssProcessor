This section shows the control and data flow behind the algebra of the other
chapters. For the single-receiver path it gives the preparation of a run
(\Cref{fig:ppp-setup}), the per-epoch loop (\Cref{fig:epoch-loop}) and the
shared geometry kernel behind the three differencing regimes
(\Cref{fig:differencing}). For the real-time path it gives the order of the
seams of one epoch, with the pre-update innovation screen
(\Cref{fig:rt-seams}), the SSR correction pipeline (\Cref{fig:ssr-pipeline})
and the streaming front end that feeds it (\Cref{fig:rt-stream}). For the
network estimator it gives the joint estimator (\Cref{fig:net-flow}), the
structure of a run (\Cref{fig:net-run}), the epoch before and after the solve
(\Cref{fig:net-spine-pre,fig:net-spine-post}), the fourteen stages of the solve
(\Cref{fig:net-solve}), the emission (\Cref{fig:net-emit}) and the harvest of
the carried state (\Cref{fig:net-harvest}). Each box names the function or
class that implements the step, so the diagrams also serve as a map into
\texttt{src/}. The diagrams are maintained by hand and simplify the code: they
show the main sequence, not every gate or diagnostic.

\texttt{obs\_ssr\_sync\_max\_hold\_s} (default \SI{30}{s}) latches a degraded
