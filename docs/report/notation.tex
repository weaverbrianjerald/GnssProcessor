\paragraph{Indices and sets.}
We use lower-case Latin letters for indices and calligraphic upper-case
for sets:
\begin{itemize}[leftmargin=*, itemsep=0pt]
\item $\rx \in \rxset$ is the receiver.  Single-receiver modes (PPP,
      PPP-RTK) have $|\rxset| = 1$; baseline modes have a fixed
      reference and one or more rovers; the network producer
      (\texttt{PPP\_RTK\_Network}) carries a peer set of
      $|\rxset| \ge 2$ stations (50--305 in practice) with no
      reference/rover asymmetry.
\item $g \in \sysset = \{\text{GPS}, \text{GAL}, \text{BDS},
      \text{GLO}, \text{QZS}, \dots\}$ is the constellation.
\item $\sat \in \satset{g}$ is a satellite of constellation $g$.
      $\piv{g}$ denotes the pivot satellite of constellation $g$
      under the BSSD parameterisation (\Cref{sec:diff}).
\item $\sigl \in \sigset$ is the signal/observation type, identified by
      its RINEX-3 three-character code (e.g.\ \texttt{C1C}, \texttt{L2W},
      \texttt{L5X}).
\item $k \in \mathbb{N}$ is the discrete epoch index.
\end{itemize}

\paragraph{Vectors and matrices.}
Bold lower-case for vectors ($\bm{x}$, $\rxpos$); bold upper-case for
matrices ($\jacH$, $\covM$).  $\bm{a}^{\Tr}$ is the transpose.
A hat denotes a state estimate; a tilde a one-step prediction:
$\hat{\stateV}_{k|k}$ vs.\ $\tilde{\stateV}_{k|k-1}$.

\paragraph{Observables.}
For each receiver/satellite/signal triple, the engine consumes two
real-valued observables (in metres) per epoch:
\begin{itemize}[leftmargin=*, itemsep=0pt]
\item $\code^\sat_{\rx,\sigl}$ is the pseudorange (code), in metres.
\item $\phaseo^\sat_{\rx,\sigl}$ is the carrier phase, scaled to metres
      via $\lambda_\sigl$.  Beyond the range, clock, and atmosphere
      terms it shares with the code, its ambiguous (non-range) part is
      $\lambda_\sigl N^\sat_{\rx,\sigl}$ plus the fractional phase
      biases $b_{\rx,\sigl} - b^\sat_\sigl$ (\Cref{eq:obs-phase}).
\end{itemize}
Where the distinction matters, $\sigl$ may further denote the band
($L_1, L_2, L_5, \ldots$) and the tracking attribute (e.g.\ \texttt{C}, \texttt{W}, \texttt{X}).
The leading observable-type letter (\texttt{C}/\texttt{L}) selects code
vs.\ phase; the frequency-only quantities $f_\sigl$, $\lambda_\sigl$, and
$N^\sat_{\rx,\sigl}$ depend only on the (band, attribute) part, so a code
and its sibling phase share them.  This matches the state keys, which
carry the full phase code for ambiguities (\texttt{"G01\_L1C"}) but only
the band digit for receiver code biases (\texttt{"GPS\_IFB2"}).

\paragraph{Frequencies and wavelengths.}
$f_\sigl$ is the carrier frequency (Hz) and $\lambda_\sigl = \sLight / f_\sigl$
the wavelength (m).  The frequency-squared scaling factor used to
project the L1-equivalent slant ionospheric delay onto signal $\sigl$
is
\begin{equation}
\mu_\sigl \;:=\; \frac{f_1^2}{f_\sigl^2}.
\label{eq:iono-scaling}
\end{equation}
Here $f_1$ is the GPS~L1 frequency ($1575.42$~MHz), used as the common
reference for \emph{every} constellation, not the band-1 frequency of
the satellite's own system.  The estimated state $I^\sat_{\rx,1}$ is
therefore GPS-L1-equivalent even for BDS/GLO/GAL satellites
(\texttt{MeasurementModel::buildJacobianRow}: \texttt{f\_ref =
Constants::GPS\_L1\_FREQ}).

\paragraph{Differencing operators.}
Three differencing operations recur throughout the document:
\begin{equation*}
\bsd{q^{\sat,\piv{g}}_{\rx,\sigl}}
  := q^\sat_{\rx,\sigl} - q^{\piv{g}}_{\rx,\sigl},
\quad
\brd{q^{\sat}_{\rx_1\rx_2,\sigl}}
  := q^\sat_{\rx_1,\sigl} - q^\sat_{\rx_2,\sigl},
\quad
\dd{q^{\sat,\piv{g}}_{\rx_1\rx_2,\sigl}}
  := \bsd{\big(\brd{q^\sat_{\rx_1\rx_2,\sigl}}\big)}.
\end{equation*}
Read $\bsd{q}$ as ``between-satellite single difference of $q$
relative to pivot $\piv{g}$,'' $\brd{q}$ as ``between-receiver
single difference,'' and $\dd{q}$ as ``double difference.''

\paragraph{Sign conventions.}
We adopt the convention that the slant ionospheric delay $I^\sat_{\rx,\sigl}$
enters \emph{additively} on the code observable and \emph{subtractively}
on the carrier phase observable; this is the source of the well-known
``code--phase divergence.''  All other range-additive terms (geometry,
clocks, troposphere, biases) carry the same sign on both observables.
See \Cref{eq:obs-code,eq:obs-phase} for the explicit equations.
