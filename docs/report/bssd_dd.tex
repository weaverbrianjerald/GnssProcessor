% ============================================================
%  Differencing transformations: BSSD and DD
% ============================================================

PPP-RTK and baseline modes do not consume the undifferenced
observations of \Cref{eq:obs-code,eq:obs-phase} directly.  Each forms
a linear combination across satellites (BSSD), receivers (BRSD), or
both (DD), absorbing common-mode terms into the cancellation and
recovering integer-friendly residual structure.  This section gives
both the algebraic cancellations and the matrix-form S-transforms
that map undifferenced parameters to differenced ones.

\subsection{Between-satellite single difference (BSSD)}\label{sec:bssd}

For each constellation $g$, choose a pivot satellite $\piv{g}$
(elected by \texttt{PivotManager::selectPivotCandidates} under the
``sticky pivot'' retention policy; the selection ordering is detailed
in the \emph{Pivot selection} note below).  For
any non-pivot satellite $\sat \in \satset{g} \setminus \{\piv{g}\}$
and signal $\sigl$, define
\begin{align}
\bsd{\code^{\sat,\piv{g}}_{\rx,\sigl}}
&:= \code^\sat_{\rx,\sigl} - \code^{\piv{g}}_{\rx,\sigl}, \notag\\
\bsd{\phaseo^{\sat,\piv{g}}_{\rx,\sigl}}
&:= \phaseo^\sat_{\rx,\sigl} - \phaseo^{\piv{g}}_{\rx,\sigl}.
\end{align}
Substituting \Cref{eq:obs-code,eq:obs-phase} and cancelling the
receiver-side common terms ($\sLight\,\mathrm{d}t_\rx$,
$\sLight\,\delta t^{(g)}_\rx$, $B_{\rx,\sigl}$, $b_{\rx,\sigl}$) yields
\begin{empheq}[box=\fbox]{align}
\bsd{\code^{\sat,\piv{g}}_{\rx,\sigl}}
&\;=\; \bsd{\geomrange^{\sat,\piv{g}}_\rx}
     - \sLight\,\bsd{\mathrm{d}t^{\sat,\piv{g}}}
     + \bsd{T^{\sat,\piv{g}}_\rx}
     + \mu_\sigl\,\bsd{I^{\sat,\piv{g}}_{\rx,1}}
     - \bsd{B^{\sat,\piv{g}}_\sigl}
     + \bsd{\varepsilon^\code}, \label{eq:bssd-code}\\
\bsd{\phaseo^{\sat,\piv{g}}_{\rx,\sigl}}
&\;=\; \bsd{\geomrange^{\sat,\piv{g}}_\rx}
     - \sLight\,\bsd{\mathrm{d}t^{\sat,\piv{g}}}
     + \bsd{T^{\sat,\piv{g}}_\rx}
     - \mu_\sigl\,\bsd{I^{\sat,\piv{g}}_{\rx,1}}
     + \lambda_\sigl\,\bsd{N^{\sat,\piv{g}}_{\rx,\sigl}}
     - \bsd{b^{\sat,\piv{g}}_\sigl}
     + \bsd{\varepsilon^\phaseo}. \label{eq:bssd-phase}
\end{empheq}
The cancellations are exact only when both observations enter the
filter with the same modelling: same tropospheric mapping (which is
why $\bsd{T}$ is small but not zero), same antenna PCV correction,
and so on.

The receiver-bias cancellation of $B_{\rx,\sigl}$ in
\Cref{eq:bssd-code} holds for CDMA constellations, whose group delay is
a single per-signal receiver term.  GLONASS is the exception: its FDMA
inter-frequency biases are per-FCN-slot states, so two satellites on
different slots carry different receiver delays and the term does
\emph{not} cancel between them --- a residual
$B^{(k(\sat))}_{\rx,\sigl} - B^{(k(\piv{g}))}_{\rx,\sigl}$ survives the
single difference.  Accordingly \texttt{BssdTransform} zeroes the
receiver-DCB columns after differencing \emph{except} the per-slot
GLONASS IFB states (guarded by \texttt{StateKeys::isGlonassPerSlotIfbKey}),
and \texttt{PivotManager} bars GLONASS from pivot election, for the same
reason.  GLONASS BSSD is default-OFF
(\texttt{estimation.between\_satellite\_sd.enable\_glonass}); when
enabled, \Cref{eq:bssd-code} acquires the surviving inter-slot IFB
difference as an additional estimated column.

\paragraph{Pivot selection.}
Election is not by elevation alone.  The primary key is a
\emph{hard} lexicographic tier on phase-signal coverage: a
full-coverage candidate outranks any partial-coverage candidate
regardless of its score.  Only within a coverage tier does the
additive score
$-\min\!\big(1,\sqrt{\sigma^2_{\hat N,\max}}\big) + \mathrm{el}/90 -
\tfrac12\,\mathbb{1}[\mathrm{el} < 20^\circ]$
apply, in which float-ambiguity convergence
$\sqrt{\sigma^2_{\hat N,\max}}$ and elevation enter as co-equal terms
(with a hard low-elevation guardrail below $20^\circ$).  Layered on top
is an ephemeris-freshness bar: a candidate whose broadcast
$|\text{obs} - \text{toe}|$ exceeds its constellation's freshest
qualified peer by more than \texttt{kPivotToeSpreadMaxS} ($\SI{1200}{s}$)
is barred from \emph{pivot} election (though still usable as a non-pivot),
which prevents a stale-eph pivot from stepping every SD row it anchors.
Candidates below \texttt{estimation.between\_satellite\_sd.pivot\_min\_elevation}
are excluded outright.  The baseline DD path scores differently:
\texttt{DdPivotManager} ranks on $\text{avg\_snr} + 0.01\cdot\text{num\_sigs}$
and does not use elevation.

\paragraph{Pivot transitions.}
A handover fires on two kinds of trigger.  The visibility-driven one
is simple --- when the incumbent pivot leaves the visible set,
$\piv{g}$ is re-elected from the remaining satellites --- but the
dominant one in practice is \emph{event-driven}: the post-fit residual
analyser calls \texttt{PivotManager::requestForcedHandover} when the
pivot's \emph{observation} slipped while its filter \emph{state} is
still intact (so the resting \texttt{isPivotDisturbed} check, which
tests only that the pivot ambiguity sits at exactly $(0,0)$, would not
catch it).  The forced request carries an exclusion set so the
handover cannot bounce onto another offset satellite, a
\texttt{retired\_pivots\_this\_epoch\_} backstop that terminates cascades,
a same-epoch re-entry gate (\texttt{hasPendingForcedHandover}), and a
re-inflation set for states that absorbed a coherent pivot-side code
bias (the information-conserving transform below cannot evict that
offset on its own).  The baseline DD path exposes the symmetric
\texttt{DdPivotManager::requestForcedRerank}.  This event response is
load-bearing precisely because the pivot's states are frozen at zero
variance (below): a stiff, time-linked zero-$q$ quantity requires a
wired jump response.

On election the float ambiguities
$\{\bsd{N^{\sat,\piv{g}^{\mathrm{old}}}_{\rx,\sigl}}\}_{\sat,\sigl}$
must be re-expressed relative to $\piv{g}^{\mathrm{new}}$.  Where the
new pivot already carries an established ambiguity in the group, the
engine applies the linear S-transformation
$\stateV^{\mathrm{new}} = \bm{S}\,\stateV^{\mathrm{old}}$
with $\bm{S}$ chosen so that
$\bsd{N^{\piv{g}^{\mathrm{new}},\piv{g}^{\mathrm{old}}}_{\rx,\sigl}}$
becomes the new reference (zero), preserving the integer information
accumulated since the last fix; the covariance transforms as
$\covM^{\mathrm{new}} = \bm{S}\,\covM^{\mathrm{old}}\,\bm{S}^{\Tr}$.
When it cannot --- the new pivot has no existing ambiguity in the
$(\text{cons},\text{code})$ group (\texttt{DdPivotManager}, logged as
``reset-and-reseed''), or a disturbed pivot has no healthy replacement
in a single-satellite constellation (\texttt{PivotManager::handleDisturbedPivot}
re-zeroes $\stateV$ and the corresponding rows/columns of $\covM$ in
place) --- the transform is skipped and the stale rows are discarded and
re-seeded.  In the uncombined PPP-RTK parameterisation the same
$\bm{S}\,\covM\,\bm{S}^{\Tr}$ re-reference is applied not only to the
ambiguity block but to \emph{three} state groups ---
\texttt{reReferenceAmbiguities}, \texttt{reReferenceIonosphere}, and
\texttt{reReferenceSatBiases} --- which is why \texttt{BssdTransform}
zeroes the pivot's ionosphere and sat-bias $\bm{H}$-columns after
differencing, and why $\bsd{I^{\sat,\piv{g}}_{\rx,1}}$ in
\Cref{eq:bssd-code,eq:bssd-phase} is itself a pivot-referenced SD
quantity, not an absolute slant delay.  The S-basis constraint is
realised operationally by freezing the pivot's ambiguity, ionosphere,
and sat-bias covariances to exactly zero (and suppressing their process
noise) --- the very condition \texttt{isPivotDisturbed} tests against.

\texttt{PivotManager::getCleanHandovers} classifies each transition as
lossless-invertible (\emph{clean}) or discontinuous
(disturbed/forced/re-seeded), so the RTS smoother can inverse-reference
across a clean handover rather than force a segment boundary; the
losslessness claim above holds only for the clean subset.
These are two distinct code paths sharing the algebra above: in PPP-RTK
the pivot re-election and the ``sticky-pivot'' retention policy live in
\texttt{filter/PivotManager}, whereas the baseline DD path performs the
analogous re-reference through the ambiguity-rename S-transform in
\texttt{filter/DdPivotManager}, governed by the
\texttt{baseline.enable\_pivot\_handover} flag.

\subsection{Between-receiver single difference (BRSD)}\label{sec:brsd}

In baseline modes there is at least one rover $\rx_{\mathrm{rov}}$ and
exactly one fixed-coordinate reference $\rx_{\mathrm{ref}}$.  The
BRSD operator forms
\begin{equation}
\brd{\code^{\sat}_{\rx_{\mathrm{rov}}\rx_{\mathrm{ref}},\sigl}}
\;:=\;
\code^\sat_{\rx_{\mathrm{rov}},\sigl} - \code^\sat_{\rx_{\mathrm{ref}},\sigl},
\end{equation}
and analogously for $\brd{\phaseo}$.  The cancellations produced by
$\brd{\cdot}$ are dual to those produced by $\bsd{\cdot}$: BRSD
cancels \emph{satellite}-side common terms ($\sLight\,\mathrm{d}t^\sat$,
$B^\sat_\sigl$, $b^\sat_\sigl$) but preserves receiver clock and
biases of \emph{both} stations.  No state-space estimation of
satellite biases is required when $\brd{}$ is applied --- they
disappear before reaching the filter.

\subsection{Double difference (DD)}\label{sec:dd}

The composition $\dd{\cdot} = \bsd{\big(\brd{\cdot}\big)}$ is
order-independent up to noise correlation: $\bsd{\big(\brd{\cdot}\big)} = \brd{\big(\bsd{\cdot}\big)}$.
Applying it to the carrier-phase model and collecting common-mode
cancellations:
\begin{equation}
\dd{\phaseo^{\sat,\piv{g}}_{\rx_{\mathrm{rov}}\rx_{\mathrm{ref}},\sigl}}
\;=\;
\dd{\geomrange^{\sat,\piv{g}}_{\rx_{\mathrm{rov}}\rx_{\mathrm{ref}}}}
+ \dd{T^{\sat,\piv{g}}_{\rx_{\mathrm{rov}}\rx_{\mathrm{ref}}}}
- \mu_\sigl\,\dd{I^{\sat,\piv{g}}_{\rx_{\mathrm{rov}}\rx_{\mathrm{ref}},1}}
+ \lambda_\sigl\,\dd{N^{\sat,\piv{g}}_{\rx_{\mathrm{rov}}\rx_{\mathrm{ref}},\sigl}}
+ \dd{\varepsilon^\phaseo}.
\label{eq:dd-phase}
\end{equation}
What survives in \Cref{eq:dd-phase} is precisely the geometry term
(linear in the rover position perturbation), the differential
atmospheric delays, and the integer DD ambiguity --- the structural
form that makes carrier-phase RTK possible.

\paragraph{Short vs.\ long baselines.}
On short baselines (\,$\lesssim \SI{10}{km}$\,) the differential
atmospheric terms in \Cref{eq:dd-phase} are negligible at the
millimetre level and need not be modelled.  As baseline length grows,
the differential ionosphere $\dd{I}$ scales linearly with separation
and saturates at typically \SI{1}{m} for separations of a few hundred
kilometres, swamping the carrier wavelength.  Two mitigations are
available in \texttt{GnssProcessor}:
\begin{itemize}[leftmargin=*, itemsep=0pt]
\item \texttt{baseline.use\_iono\_free} forms the dual-frequency
      ionosphere-free combination at the DD level, eliminating the
      first-order ionospheric term at the cost of a non-integer
      ambiguity (AR is automatically excluded for IF rows) and
      $\sim 3\times$ amplified code noise;
\item \texttt{baseline.estimate\_differential\_tropo} adds a single
      $\Delta\zwd_{\rx_{\mathrm{rov}}\rx_{\mathrm{ref}}}$ state with
      slow random-walk dynamics, capturing the residual differential
      wet delay that survives the BRSD on baselines with significant
      altitude difference.
\end{itemize}

\subsection{S-transform structure}

Both BSSD and DD admit a matrix-form representation as
$\stateV_{\mathrm{diff}} = \bm{S}\,\stateV_{\mathrm{undiff}}$ with
$\bm{S}$ acting as a block design transform.  For BSSD restricted to
the ambiguity block of one constellation $g$ on one signal $\sigl$,
with $|\satset{g}|$ tracked sats, $\bm{S}$ is a
$(|\satset{g}|-1) \times |\satset{g}|$ matrix of the form
\begin{equation}
\bm{S}_{\mathrm{BSSD}}
\;=\;
\begin{bmatrix}
1 & 0 & \cdots & 0 & -1 & 0 & \cdots & 0 \\
0 & 1 & \cdots & 0 & -1 & 0 & \cdots & 0 \\
\vdots & & \ddots & & \vdots & & \\
0 & 0 & \cdots & 0 & -1 & 0 & \cdots & 1
\end{bmatrix},
\end{equation}
where the column of $-1$'s sits at the index of the pivot
$\piv{g}$.  The DD operator is the \emph{composition} of the two
single-difference operators applied in sequence,
$\bm{S}_{\mathrm{DD}} = \bm{S}_{\mathrm{BSSD}}\,\bm{S}_{\mathrm{BRSD}}$,
realised in code as \texttt{BrsdTransform::apply} followed by
\texttt{BssdTransform::differenceBrsd}
(\texttt{include/measurement/BssdTransform.hpp}).  Only on a fully
populated satellite\,$\times$\,receiver observation grid does this
composition coincide with the Kronecker product
$\mathbf{D}_{\mathrm{sat}} \otimes \mathbf{D}_{\mathrm{rx}}$ of the
between-satellite and between-receiver differencing matrices acting on
the vectorised observations --- a useful mental model, but not what the
non-rectangular real-data case computes.  The
transformed covariance is $\covM_{\mathrm{diff}} = \bm{S}\,\covM_{\mathrm{undiff}}\,\bm{S}^{\Tr}$,
a generally dense matrix even when $\covM_{\mathrm{undiff}}$ is
diagonal (because each differenced row borrows from the same pivot
column).  This dense correlation structure is the algebraic reason
DD-based filters cannot be naively implemented as independent
per-pair scalar updates --- the correctly correlated joint update is
what unlocks integer ambiguity recovery via the LAMBDA decorrelation.
The general theory and a thorough catalogue of admissible
S-transforms is given in \textcite{teunissen1985generalised} and in
the rank-defect treatment of \textcite{deJonge1998processing}.

\paragraph{Implementation notes.}
Two facts about how \texttt{GnssProcessor} realises the transforms above
are worth stating explicitly.  First, the chosen S-system is never
materialised as an explicit minimum-constraint $\bm{S}$-basis matrix; it
is realised \emph{implicitly} through the pivot-differencing operator
(\texttt{measurement/BssdTransform}), a faithful, S-basis-invariant
realisation of the uncombined parameterisation of
\textcite{odijk2003fast}.  The three regimes --- undifferenced, BSSD,
and DD --- are dispatched polymorphically by a \texttt{DifferencingMode}
strategy in \texttt{measurement/MeasurementBuilder}, not by inline
config branches.  Second, integer recovery on a DD row requires that all
four contributing observations share the same RINEX signal code.  The
row is marked \texttt{integer\_capable} only when all three conjuncts
hold: \texttt{!brsd\_aliased} on \emph{both} the $\sat_i$ and pivot BRSD
entries (rover and reference agree on each, i.e.\ no cross-attribute
alias) \emph{and} the rover uses the same code on $\sat_i$ as on the
pivot ($\texttt{rov\_code}_i = \texttt{rov\_code}_{\text{piv}}$).  The
third conjunct is independent of the \texttt{brsd\_aliased} flags: a row
can be un-aliased on both entries yet still carry a non-integer DCB/IFB
residual if the rover mixes codes across $\sat_i$ and the pivot.  Rows
failing any conjunct are carried as float and excluded from ambiguity
resolution.
