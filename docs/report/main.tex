\section{Introduction}\label{sec:intro}

This document is the mathematical companion to \texttt{GnssProcessor}, a
C\texttt{++}17 post-processing and real-time GNSS engine implementing
PPP, PPP-RTK, and double-differenced baseline modes.  Its scope is
deliberately narrow:
\begin{itemize}[leftmargin=*]
\item State vector layout (\Cref{sec:state}) --- which states the
      filter carries and when each is enabled.
\item Observation equations (\Cref{sec:obs}) --- the
      \emph{uncombined} pseudorange and carrier-phase models the
      filter linearizes around.
\item Differencing transformations (\Cref{sec:diff}) --- the
      between-satellite single-difference (BSSD) used in PPP-RTK and
      the double-difference (DD) used in baseline modes, including
      the S-transform structure that maps undifferenced parameters
      to differenced ones.
\end{itemize}

Implementation details (function signatures, class responsibilities,
config field reference) live in the headers under \texttt{include/}
and are rendered via Doxygen.  When this document references a
specific algorithmic component, it cites the source file directly
(e.g.\ \texttt{src/core/filter/KalmanFilter.cpp}).

The notation follows the IGS conventions adopted by
\textcite{subirana2013gnss} and \textcite{teunissen2017handbook};
see \Cref{sec:notation} for the symbol table this document depends on.
