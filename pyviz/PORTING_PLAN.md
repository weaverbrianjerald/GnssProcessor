### plotIonosphere.m
- **transforms:** GPS-time -> datetime: T.utc = datetime(1980,1,6) + seconds(week*7*86400 + tow_s). NO leap-second adjustment — displayed datetime IS GPS time (despite the column being named 'utc').; satellite -> categorical(string(satellite)).; System derivation when 'system' column absent: map by leading char of satellite ID — G->GPS, E->Galileo, R->GLONASS, C->BeiDou, J->QZSS, S->SBAS, else 'Unknown'. Then system -> categorical.; mapping_factor derivation when absent: thinShellMappingFactor(elevation_deg) — single-layer thin-shell model, Re=6371230.0 m, H=450e3 m: sin_zp=(Re/(Re+H))*cos(el_rad); cos_zp=sqrt(max(0,1-sin_zp^2)); mf=1/cos_zp; NaN where el not finite or el<=0.; vtec_m derivation when absent: iono_m / mapping_factor.; insertGapBreaks(t,y,gapFactor): sort by time, dtSec=seconds(diff(t)), medDt=median(dt) (fallback 1 if non-finite or <=0); declare gap where dt > gapFactor*medDt and insert one NaT/NaN row per gap so plot() breaks instead of bridging. Reused by Figs 1-4.; collectPivotHandovers(T): per-constellation, unique-epoch chronological pivot_satellite series; handover = epoch where pivot_satellite changed from previous AND neither old nor new is empty string. Returns containers.Map(system->datetime[]).; reReferenceIonoToFirstPivot(T) (mode 'firstPivot', the DEFAULT): per constellation, walk unique epochs chronologically accumulating offset O. At each handover P_old->P_new, find the NEW pivot's iono_m at the PREVIOUS epoch (which in the old frame equals I_Pnew - I_Pold) and add it to O. Apply O additively to EVERY row at the current epoch (pivot row raw value is 0 -> becomes O). Then recompute vtec_m = iono_m/mapping_factor. If new pivot not visible at previous epoch, O is not bridged (residual jump remains). std_m is NOT re-propagated (documented lower-bound caveat). No-op if pivot_satellite column missing or all empty.; Per-sat sigma band split: build lo=vals-err and hi=vals+err via insertGapBreaks, then segment on NaN/NaT mask using diff-of-mask edge detection (segStart=find(diff([true;mask])==-1), segEnd=find(diff([mask;true])==1)); each segment filled as a closed polygon [tt;flipud(tt)],[lo;flipud(hi)].; Sky plot color clipping via 2nd/98th percentile (quantile 0.02/0.98) of iono_m for a shared symmetric-ish color scale.; satColorRow / localColorRow: parse PRN from satellite chars 2-3 (str2double of satStr(2:3)); fall back to global index in satList; wrap modulo palette size; clamp to >=1.

## 2. Union of MATLAB builtins/toolboxes → Python equivalents

**I/O & path**
- `readtable(...,'TextType','string')` → `pandas.read_csv(dtype_backend default; keep id cols as str)`
- `fileread`+`jsondecode` → `json.loads(Path.read_text())`
- `isfile`/`isfolder`/`dir().bytes`/`fullfile` → `os.path.isfile`/`isdir`/`os.path.getsize`/`os.path.join`
- `fopen(...,'UTF-8')`+`textscan('%s','\n')` (LCF) → `open(p,encoding='utf-8').read().splitlines()`

**Time**
- `datetime(1980,1,6)+seconds(week*7*86400+tow_s)` → `pd.Timestamp('1980-01-06') + pd.to_timedelta(week*604800+tow_s, unit='s')` — **GPS time, NO leap seconds** (universal across the suite)
- `datenum` (ambiguity band x) → `matplotlib.dates.date2num`
- `datetick('x','keeplimits')` → `mdates.AutoDateLocator`/`DateFormatter`

**Geodesy (Mapping Toolbox)**
- `ecef2lla` → `pymap3d.ecef2geodetic(...)` (returns lat,lon **deg**, h m) — or hand-rolled Bowring
- `ecef2enu(...,'degrees')` → `pymap3d.ecef2enu(x,y,z,lat0,lon0,h0,deg=True)`
- `referenceEllipsoid('wgs84')` → pymap3d default WGS84 / `pyproj` CRS; constants a=6378137, f=1/298.257223563
- LCF `ecef2geo`/`geo2ecef`/`enu_rot` are already hand-rolled local funcs → port verbatim as numpy

**Stats (watch normalization)**
- `std` → `np.std(..., ddof=1)` (MATLAB default = sample/N-1) — **applies to every mu/sigma annotation and summary**
- `median/mean/min/max` `'omitnan'` → `np.nan*` variants
- custom nearest-rank `pctl` (strips, iono, etc.) → `np.percentile(..., method='nearest')` (NOT default linear) — **load-bearing for caxis parity**
- LCF `pctl` (linear interp on linspace grid) → `np.interp` (different impl from the strip pctl — keep both)
- `histcounts`/`histogram` → `np.histogram`; log edges → `np.logspace`
- `rms` → `np.sqrt(np.mean(x**2))`
- `round` (MATLAB = half-away-from-zero) → use explicit `np.floor(x+0.5)` where it gates integers (dN, indices), NOT `np.round` (banker's)

**Reshape / grouping**
- `sub2ind` → `np.ravel_multi_index` or direct 2D assignment
- `ismember` → index map / `pd.Index.get_indexer` (treat -1/not-found as drop; MATLAB returns 1-based, 0=miss)
- `findgroups`+`splitapply(@first)` → `df.groupby(...).head(1)` / `.first()`
- `accumarray` → `groupby.size()` / `np.bincount`
- `unique(...,'stable')` → `pd.unique` / `dict.fromkeys` (NOT `np.unique`, which sorts)
- `sortrows` → `df.sort_values` / `np.lexsort`
- `str2double(sat(2:3))` (PRN parse) → `int(s[1:3])` in try/except → NaN; stable sort with NaN-last
- `containers.Map` → `dict`/`collections.Counter`

**Plotting → matplotlib (behind a Backend interface)**
- `imagesc`+`AlphaData(~isnan)` → `imshow`/`pcolormesh` with `np.ma.masked_invalid` + `cmap.set_bad(alpha=0)` (NaN transparent, never colormap-extreme)
- `tiledlayout`/`nexttile` (incl. nested outer-1×N / inner-N×1) → `GridSpec`/`subplots`/`subgridspec`
- `yyaxis` → `ax.twinx()`; `set(gca,'YScale','log')` → `ax.set_yscale('log')`
- `yline`/`xline` → `axhline`/`axvline`; `linkaxes('x')` → `sharex`
- `area` (stacked) → `stackplot`; `stem('filled')` → `ax.stem`; `barh`+`YDir reverse` → `ax.barh`+`invert_yaxis`
- `fill`/`fill_between` (sigma bands, ellipses) → `ax.fill`/`Polygon`
- `polaraxes`/`polarscatter` → polar projection (`set_theta_zero_location('N')`, `set_theta_direction(-1)`)
- `colorbar` custom ticks/labels → `fig.colorbar` + `set_ticks`/`set_ticklabels`; categorical → `ListedColormap`+`BoundaryNorm`
- `text('Units','normalized')` → `ax.text(transform=ax.transAxes)`
- `datacursormode`/`DataTipTemplate` (signals viewer, LCF) → `mplcursors` or skip (guard non-fatal)
- TeX vs `Interpreter 'none'` → mathtext per-text for `\mu \sigma \lambda`; literal for sat/signal labels (so `L1C/L2W`, `_` not mangled)

**Colormaps**
- `turbo` → matplotlib `'turbo'` (native)
- `parula` → **vendor an RGB table** (no matplotlib equiv); used only as stripColormap fallback
- `viridis/cividis/magma/inferno` → matplotlib native OR the 11-anchor interp (port anchors for byte-parity)
- `vik` (Crameri), `rdbu`, `bwr` → vendor vik 11-anchor table; `rdbu` via `'RdBu'`; `bwr` hand-built per spec (asymmetric row split on odd n — do NOT use mpl `'bwr'`)
- `distinguishable_colors` → vendored ~1000-color qualitative palette + `tab20`/lines fallback; index by PRN/sat (1-based care)
